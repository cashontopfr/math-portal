# MathVerse - Mathematics Learning Portal

A modern math learning hub integrated with official Khan Academy courses and topics, featuring an interactive Practice Arena.

## Features
- **Search & Discovery**: Instantly filter math topics by keywords, tags, or subject category (Foundations, Algebra, Geometry, Calculus, Advanced Math, Statistics).
- **Khan Academy Integration**: Curated direct links to Khan Academy lessons, units, and practice tracks.
- **Interactive Practice Arena**: Unlimited auto-generated mental math, basic algebra equations, and geometry questions with real-time feedback, scoring, and streaks.
- **Modern Responsive Design**: Clean dark theme with smooth hover animations, badge levels, and mobile-friendly layouts.

## Getting Started
Simply double-click `OPEN.bat` or open `index.html` in any modern web browser.
